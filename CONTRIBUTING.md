# Contributing to FarmLand

Thank you for your interest in contributing to FarmLand! 🌾

## How to Contribute

1. Fork the repository.
2. Create a new branch.
3. Make your changes.
4. Test your changes.
5. Commit your work.
6. Submit a Pull Request.

## Development Guidelines

- Keep the code clean and readable.
- Use reusable React components.
- Keep the UI mobile-friendly.
- Do not include private keys or sensitive information.
- Test buttons and navigation before submitting changes.

## Areas for Contribution

We welcome improvements in:

- UI and UX
- Mobile responsiveness
- Solana integration
- Wallet support
- Testnet transactions
- FarmScore improvements
- Marketplace features
- Portfolio analytics
- Documentation

## Reporting Issues

If you find a bug or have an idea for a feature, please open an issue with:

- A clear title
- Description of the problem or idea
- Steps to reproduce, if applicable
- Screenshots, if helpful

## Code of Conduct

Please be respectful and constructive when contributing to the project.
