# 🌾 FarmLand

## Tokenized Farmland Ownership Platform

FarmLand is a modern web application that explores how real-world farmland ownership can be represented through digital units on blockchain infrastructure.

Users can explore farmland opportunities, review ownership information, verify properties, check FarmScore ratings, purchase farmland units on testnet, and track their portfolio.

---

## ✨ Features

### 🌾 Property Discovery
Explore farmland properties and view important property information.

### 📄 Ownership
Review farmland ownership details and ownership records.

### 🛡️ Verification
Property verification flow for improved transparency and trust.

### 📊 FarmScore
A simple farmland scoring system for evaluating property quality and investment factors.

### 🏪 Marketplace
Browse available farmland opportunities and select properties.

### 🪙 Buy Units
Choose the number of farmland units to purchase and review the purchase summary.

### 💳 Testnet Payment
Simulated testnet transaction flow for demonstrating the purchase experience.

### 📈 Portfolio
Track purchased farmland units, total investment, and active farmland ownership.
