# FarmLand Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful, and inclusive environment for everyone contributing to FarmLand.

## Expected Behavior

When participating in this project, please:

- Be respectful and constructive.
- Welcome different ideas and perspectives.
- Provide helpful feedback.
- Focus on improving the project.
- Respect the privacy and security of others.
- Report security issues responsibly.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or personal attacks.
- Discrimination or hateful language.
- Sharing private information without permission.
- Intentionally disrupting project discussions.
- Publishing security vulnerabilities irresponsibly.
- Attempting to steal user information, wallet credentials, or private keys.

## Contributions

All contributors should:

- Write clear and respectful communication.
- Test their changes when possible.
- Avoid committing sensitive information.
- Follow the project's security guidelines.
- Help maintain a positive community.

## Enforcement

Project maintainers may remove, edit, or reject contributions or comments that violate this Code of Conduct.

## Reporting Issues

If you experience unacceptable behavior, please report it privately to the project maintainer.
