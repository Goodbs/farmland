# Security Policy

## Supported Versions

FarmLand is currently a prototype and demonstration project.

Security updates apply to the latest version of the project.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅ |
| Older versions | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability, please do not publish sensitive details publicly.

Instead, report the issue privately to the project maintainer with:

- A description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Screenshots or logs, if applicable

## Security Guidelines

When contributing to FarmLand:

- Never commit private keys.
- Never commit wallet seed phrases.
- Never commit API secrets.
- Never commit `.env` files.
- Validate user inputs.
- Verify blockchain transactions before confirming ownership.
- Use trusted wallet and blockchain libraries.
- Test smart contract interactions carefully.

## Wallet Safety

FarmLand should never request:

- Wallet seed phrases
- Private keys
- Recovery phrases

Users should always verify transaction details in their wallet before approving a transaction.

## Prototype Disclaimer

The current version of FarmLand is a prototype.

Do not use the application for real financial transactions or real-world farmland ownership without proper security audits, legal review, and production blockchain infrastructure.
